# ⚔ Pixel Hero ⚔

Моя самая первая игра, написанная с нуля на чистом HTML5 Canvas и JavaScript. 
Я начал изучать программирование совсем недавно, и это мой первый большой проект. Не судите строго!

## 🎮 Об игре
Ты — отважный герой в пиксельном мире. Древнее зло пробудилось, и только ты можешь очистить землю от монстров. 
Твоя задача — сражаться с врагами, собирать зеленые рупии и сердца, и продержаться как можно дольше.

## 🕹 Управление
**На компьютере:**
* `W A S D` или `Стрелочки` — движение
* `ПРОБЕЛ` или `J` — удар мечом

**На телефоне:**
* Виртуальный джойстик слева — движение
* Красная кнопка с мечом справа — атака

## 🛠 Технические детали
* Движок: Чистый JavaScript (без сторонних библиотек).
* Графика: Рисуется кодом прямо на холсте (Canvas API).
* Звук: Синтезируется через Web Audio API (без внешних файлов).
* Карта: Генерируется процедурно при каждом запуске.

## 🚀 Как играть
